# sigma-clicker
Présentation du jeu SIGMA BRAINROT CLICKER est un jeu par navigateur de type clicker / idle rapide, décalé et basé sur la culture mème (Skibidi, Rizz, Mewing, GigaChad). Le joueur incarne un "Sigma" en pleine ascension, dont l'objectif est d'accumuler un maximum de Points Brainrot en cliquant frénétiquement et en optimisant ses gains passifs.
